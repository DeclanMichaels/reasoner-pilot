# CMRB pilot data (CSV)

Tidy, long-format tables of the Cross-Cultural Moral Reasoning Benchmark pilot. Every table is the same underlying data as the raw JSON runs, reshaped so it opens in any spreadsheet and joins on `scenario_id` (and `axis_id`). The raw JSON runs under `runs_v2/` remain the source of truth; these CSVs are generated by `private/viz/build_csv.py` and can be regenerated at any time.

Scores here (and in the report) are produced by the scoring function in `scenario_bank.py`: each option carries a signed loading from -1 to +1, a respondent's axis score is the loading-weighted average of the points they allocated, and the judgment and reasoning questions combine 0.6 to 0.4. See appendix section A2.

## Files

`scenarios.csv` (the instrument). One row per option. Columns: `scenario_id`, `axis_id`, `axis_name`, `has_human_baseline` (1 for the 12 scenarios with human data), `question` (judgment or reasoning), `option_index`, `option_text`, `loading` (the option's signed pull on its axis, -1 to +1).

`model_scores.csv` (derived positions). One row per model, framing, subset, and axis. Columns: `model`, `lab`, `frame`, `subset` (`b12` = the 12 human-baseline scenarios, `all48` = all scenarios), `axis_id`, `axis_name`, `score` (-1 to +1), `run_sd` (standard deviation of that score across the 5 reruns; the viewer's run-spread overlay).

`model_allocations.csv` (raw model inputs, every rerun). One row per option of every response. Columns: `model`, `lab`, `frame`, `scenario_id`, `iteration` (0 to 4), `question`, `option_index`, `weight` (normalized points on that option). Join to `scenarios.csv` on `scenario_id` + `question` + `option_index` to attach the option text and loading.

`model_reasoning.csv` (model free text). One row per response. Columns: `model`, `lab`, `frame`, `scenario_id`, `iteration`, `extraction_failed` (1 if the allocation could not be parsed), `reasoning_text`.

`human_scores.csv` and `human_allocations.csv`. The same shape for the 68 human respondents, who are anonymized to sequential ids (`h01`..). Humans answered the 12 baseline scenarios; there are no iterations.

## Framings

`neutral` (unframed), the four cultural framings (`individualist`, `collectivist`, `hierarchical`, `egalitarian`), `irrelevant` (a mild non-moral seasonal framing, intended as a control but not a clean one), and two nonsense framings (`nonsense_geometry`, `nonsense_color`).
