# Where this work lives

Canonical index of every public location for the Reasoner pilot and the in-language MFQ-2 study.
Each home below links back to this file, so any entry point reaches the whole set.

## Locations

- **Source (data + code)** - GitHub: https://github.com/DeclanMichaels/reasoner-pilot  (living source)
- **Archived snapshot (citable)** - Zenodo: https://doi.org/10.5281/zenodo.22712502 (v1.1.0, 2026-09-11; the release
  `v1.1.0` archived by the GitHub integration). Concept DOI, resolving to the latest version:
  https://doi.org/10.5281/zenodo.22712501
- **Reports** - https://moral-os.com/papers/reasoner-pilot.html (paper, appendix) and
  https://moral-os.com/papers/inlanguage-mfq2.html (the MFQ-2 document)
- **Interactive viewers** - https://moral-os.com/experiments/reasoner-viewer.html (the pilot) and
  https://moral-os.com/experiments/inlanguage-mfq2-viewer.html (the MFQ-2 grid); `viewer.html` and
  `validity/viewer.html` in this repository
- **Preregistration** - none. Both documents are exploratory and say so; the confirmatory study,
  `reasoner-study`, carries its own preregistration.
- **Program umbrella** - https://moral-os.com  (Cross-Cultural Alignment Study)

## Version of record

The Zenodo DOI is the citable record for both documents and the archived data and code (decision
23: one deposit, the repository snapshot, both documents citing it). moral-os.com is the readable
and interactive front door; this GitHub repository is the living source. Machine-readable
identifiers are in `CITATION.cff` and `.zenodo.json`. A later release mints a new version DOI under
the same concept DOI.
